A free entry for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) bounty on make.fun: one short funny line answering a prompt.

The prompt is the excuse a printer gives after printing 200 blank pages. The joke is told in the printer's own first-person voice, and it refuses the obvious excuse — it never claims the cartridge ran out. Instead it insists the pages are a security feature: printed in invisible ink so nobody can steal the report, the paper merely classified, and its display still proudly reporting the job a success. The humour comes from the fit: a machine whose whole job is putting marks on paper produced 200 pages of nothing and calls it a triumph.

## Run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt`. The entry is 173 characters (within the 1–200 character gate), a single line, and fully deterministic: two runs write byte-identical output.
